## Task 4.5 — 采集频率自适应调节

创建 **`crawlers/rate_limiter.py`**:
```python
import time

class AdaptiveRateLimiter:
    """采集失败时自动降低频率，成功后恢复"""
    def __init__(self):
        self.fail_count = {}  # source -> int
        self.next_allowed_at = {}  # source -> monotonic timestamp

    def on_success(self, source: str):
        self.fail_count[source] = max(0, (self.fail_count.get(source, 0) - 1) // 2)
        self.next_allowed_at.pop(source, None)

    def is_paused(self, source: str) -> bool:
        """失败后只在退避窗口内跳过，窗口到期必须允许重试，不能永久暂停。"""
        return self.next_allowed_at.get(source, 0) > time.monotonic()

    def next_interval(self, source: str, base_interval_min: int) -> int:
        """失败 n 次 → base × 2^n，最多 ×8"""
        n = min(self.fail_count.get(source, 0), 3)
        return base_interval_min * (2 ** n)

    def on_failed(self, source: str, base_interval_min: int = 30):
        self.fail_count[source] = self.fail_count.get(source, 0) + 1
        self.next_allowed_at[source] = time.monotonic() + self.next_interval(source, base_interval_min) * 60
```

在 scheduler.run_crawl_task 中接入 rate_limiter：
- 成功 → on_success；失败 → on_failed
- is_paused → 本次跳过并记录退避时间；窗口到期自动重试，不能永久停采

## Task 4.7 — 数据备份脚本

创建 **`scripts/backup.py`**:
```python
#!/usr/bin/env python
"""每日自动备份：SQLite + ChromaDB → data/backups/YYYY-MM-DD/"""
import json, os, shutil, sqlite3, zipfile
from pathlib import Path
from datetime import datetime, timedelta
from config import settings

def backup_sqlite(dest_dir: str):
    """使用 SQLite backup API，保证 WAL 模式下得到一致快照。"""
    if not settings.DATABASE_URL.startswith("sqlite:///"):
        raise RuntimeError("backup_sqlite currently supports SQLite only")
    db_path = Path(settings.DATABASE_URL.removeprefix("sqlite:///"))
    if not db_path.exists():
        raise FileNotFoundError(db_path)
    source = sqlite3.connect(str(db_path), uri=False)
    target = sqlite3.connect(str(Path(dest_dir) / "jobradar.db"))
    try:
        source.backup(target)
    finally:
        target.close()
        source.close()

def backup_chromadb(dest_dir: str):
    """导出 ChromaDB collections 为 JSON"""
    import chromadb
    try:
        client = chromadb.HttpClient(host=settings.CHROMA_HOST, port=settings.CHROMA_PORT)
        for col_name in ["jobs", "resumes"]:
            try:
                col = client.get_collection(col_name)
                data = col.get(include=["embeddings", "documents", "metadatas"])
                with open(os.path.join(dest_dir, f"chroma_{col_name}.json"), "w", encoding="utf-8") as f:
                    json.dump({"ids": data["ids"],
                               "embeddings": [list(e) for e in (data.get("embeddings") or [])],
                               "documents": data.get("documents", [])}, f, ensure_ascii=False, indent=2)
            except Exception as exc:
                raise RuntimeError(f"failed to back up Chroma collection {col_name}") from exc
    except Exception:
        raise

def cleanup_old_backups(base_dir: str, keep_days: int = 30):
    """删除 keep_days 天前的备份"""
    cutoff = datetime.now() - timedelta(days=keep_days)
    for path in Path(base_dir).iterdir():
        name = path.stem if path.suffix == ".zip" else path.name
        try:
            d = datetime.strptime(name, "%Y-%m-%d")
            if d < cutoff:
                if path.is_dir():
                    shutil.rmtree(path)
                else:
                    path.unlink()
        except ValueError:
            continue

def run_backup():
    base = "data/backups"
    today = datetime.now().strftime("%Y-%m-%d")
    dest = str(Path(base) / today)
    Path(dest).mkdir(parents=True, exist_ok=True)
    try:
        backup_sqlite(dest)
        backup_chromadb(dest)
    except Exception:
        shutil.rmtree(dest, ignore_errors=True)
        raise
    # 压缩
    zip_name = dest + ".zip"
    with zipfile.ZipFile(zip_name, "w", zipfile.ZIP_DEFLATED) as zf:
        for p in Path(dest).rglob("*"):
            if p.is_file():
                zf.write(p, p.relative_to(dest))
    shutil.rmtree(dest)
    cleanup_old_backups(base, 30)

if __name__ == "__main__":
    run_backup()
```

在 scheduler 中注册：cron "0 4 * * *" 每天 4 点执行 `run_backup()`。

**Q: Boss 直聘采集失败？**
A: Boss 反爬较严。建议：
1. 暂时关闭 enabled: false
2. 在浏览器中由用户手动完成验证后再恢复采集，不自动绕过 CAPTCHA

**Q: 如何添加新的企业官网？**
A: 在 `config/sources.yaml` → `official.companies` 追加条目：
```yaml
- name: "XX公司"
  url: "https://careers.xx.com"
  parser: "generic"   # generic 为通用模板解析器
```

**Q: LLM 费用高？**
A: 降低 `config/matching_rules.yaml` 中 `vector_top_k` 到 20；减少 `max_concurrent_llm`。

## 验收标准

1. `GET /api/health` 返回 overall status + database/chromadb/heartbeat/sources 各子项检查；scheduler 状态来自独立进程的 heartbeat 或最近采集记录
2. docker compose 中所有服务配置了 healthcheck
3. 数据库迁移已执行，Job/Match/CrawlLog 的新增索引在实际数据库中可查
4. 每日 3:00 自动归档 30 天前过期岗位、清理 90 天前日志
5. 每日 4:00 自动备份生成 data/backups/YYYY-MM-DD.zip，并在临时数据库上完成一次可恢复性校验
6. 日志按轮转输出到 data/logs/jobradar.log + errors.log
7. 采集失败后按退避窗口降低频率，窗口到期自动重试，不永久停采
8. 前端路由懒加载 + WebSocket 断线自动重连
9. 前端筛选条件 URL 同步（刷新保留）
10. README.md 包含：功能介绍、Docker 部署、本地开发、FAQ
